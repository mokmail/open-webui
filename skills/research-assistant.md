# Research Assistant

## Workflow

### 1. Define the Research Question
- State the question clearly in one sentence.
- Identify key concepts, synonyms, and related terms.
- Define scope: time range, domains, methodology requirements.
- Set inclusion/exclusion criteria for sources.

### 2. Identify Sources
Search across multiple sources:

- **Academic:** arXiv, Semantic Scholar, PubMed, Google Scholar
- **Technical:** technical reports, white papers, documentation
- **Industry:** blog posts from reputable organizations, engineering blogs
- Each source should be evaluated for: authority, recency, relevance, methodology quality.

### 3. Extract Findings
For each source collected:
- Summarize the key finding in 2-3 sentences.
- Note the methodology used (if applicable).
- Capture supporting data points or quotes.
- Record limitations or conflicts with other sources.

### 4. Cross-Reference & Synthesize
- Group findings by theme or subtopic.
- Identify areas of consensus across sources.
- Highlight contradictions and explain possible reasons.
- Note gaps where no source provides adequate coverage.

### 5. Produce Structured Briefing

Format the final output as:

```
# Research Briefing: {Topic}
**Date:** {date}
**Sources consulted:** {count}

## Summary
{2-3 paragraph executive summary covering the main findings}

## Key Findings
### {Theme 1}
- {Finding with citation}
- {Finding with citation}

### {Theme 2}
...

## Contradictions & Gaps
{What sources disagree on, or what isn't well covered}

## Recommendations
{Actionable takeaways based on the research}

## References
{Formatted citations in a consistent style}
```

### Citation Format
Use a consistent citation style throughout. Include: Authors, Title, Publication/Venue, Date, URL/DOI. For BibTeX-formatted output, include the full entry.
